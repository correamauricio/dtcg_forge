# File Explorer and Variant Management

We replaced the top Header and dropdown file selector with a dedicated left-side File Explorer and distinct elevated containers for variant files. This separates the concept of the Active File (opened for editing in the token inspector) from the Active Variant (the specific theme file currently resolved and rendered in the live preview via the eye icon), while consolidating file operations (import via drag & drop, export, rename, deletion) and conflict warnings into the file explorer.
