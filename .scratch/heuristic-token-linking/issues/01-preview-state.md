# 01: Criar o estado do Default Preview Sheet

**What to build:** A aplicação ganha uma nova folha de tokens embutida (`default-preview-sheet.json`) com os "Component Tokens" que representam a interface do preview, visível e editável no painel lateral.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] O arquivo `default-preview-sheet.json` aparece automaticamente na lista de arquivos carregados pelo sistema (`token-state.service.ts`).
- [ ] O arquivo contém valores padrão que serão usados pelo live preview (ex: cores de botões e cartões).
