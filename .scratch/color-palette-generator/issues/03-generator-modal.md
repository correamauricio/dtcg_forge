# 03: Generator Modal

**What to build:** A settings modal that allows the user to write and save their custom JavaScript color generator. It's accessible via a button on the group title.

**Blocked by:** 02-compact-ui

**Status:** ready-for-agent

- [ ] Create `PaletteConfigModalComponent` to provide a text area for script editing.
- [ ] Pre-fill the text area with the default Google Material 3 generator template.
- [ ] Save the script to `PaletteGeneratorService` upon saving.
- [ ] Add a settings icon/button to the `PrimitiveGroupNodeComponent` title to trigger the modal.
- [ ] Add unit tests.
