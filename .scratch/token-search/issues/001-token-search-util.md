# 001: Motor Puro de Busca de Tokens (token-search.util.ts)

## Descrição
Implementar o utilitário de domínio puro `token-search.util.ts` e seus testes `token-search.util.spec.ts` com suporte a:
- Normalização de termos e remoção de sintaxe de alias
- Casamento por caminho de token, grupo, valor, tipo e alias
- Expansão de sub-propriedades para tokens compostos
- Filtragem de tokens planos

## Critérios de Aceitação
- Testes unitários com 100% de cobertura no utilitário
- Funções puras sem dependências externas de framework
- Suporte a busca case-insensitive e parcial

## Blockers
Nenhum.
