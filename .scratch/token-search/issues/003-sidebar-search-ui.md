# 003: UI de Busca e Feedback na Listagem (SidebarComponent)

## Descrição
Implementar a barra de busca no `SidebarComponent` com:
- Input de busca estilizado com ícone
- Tecla `Escape` para limpar
- Botão de limpar `✕` quando preenchido
- Contador de tokens quando filtrado (`X de Y`)
- Estado vazio (*Empty State*) quando nenhum token bater com a busca

## Critérios de Aceitação
- Testes unitários em `sidebar.component.spec.ts`
- Feedback visual consistente com o tema dark/slate da aplicação
